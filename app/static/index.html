Why teams pay for this

The delta is the product. A list tells you what exists today; a change feed tells you what appeared last night.

Discovery

Programs beyond the platforms

A large share of organizations that accept reports never join a platform. If they publish a security.txt, they are in this dataset, with the address to write to.

Change history

Every add, removal and edit

GET /v1/changes?since= returns added, removed and changed rows with before and after values, so a monitor polls a few hundred bytes instead of pulling the full set.

Attribution

Know where a fact came from

Each row carries its sources, whether the record came over a verified TLS chain, and the expiry state of the underlying policy file.

Quick start

One header, one endpoint. JSON in, JSON out.

curl -s "$VDP_BASE/v1/changes?since=2026-11-21T00:00:00Z&kind=added" \
  -H "X-API-Key: $VDP_KEY"
{
  "data": [
    {
      "id": 412,
      "ts": "2026-11-21T16:15:03+00:00",
      "kind": "added",
      "domain": "anthropic.com",
      "after": { "policy": "https://www.anthropic.com/responsible-disclosure-policy",
                 "expiry": "valid", "sources": ["securitytxt"] }
    }
  ],
  "meta": { "count": 1, "total": 1, "has_more": false, "generated_at": "2026-11-21T16:20:00+00:00" }
}

Full schema, filters, pagination and error codes are in the developer guide. The machine-readable contract is at /openapi.json.
