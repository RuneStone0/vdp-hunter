Developer guide

Build on the dataset

Everything here is served as JSON over HTTPS with a single API key header. The machine-readable contract lives at /openapi.json; the interactive reference is at /docs.

Base URL Authentication Rate limits Programs Change feed Data model Errors Cadence

Base URL

https://api.vdphunter.com          # hosted
http://localhost:8110              # self-hosted from the repo

Every endpoint below is relative to the base URL. Responses are application/json; charset=utf-8.

Authentication

Pass your key in the X-API-Key header. Keys are issued per customer, and every customer has the same limits. Revoking a key takes effect immediately.

curl -s "$BASE/v1/programs?limit=1" -H "X-API-Key: $VDP_KEY"

Requests without a key return 401. Requests above the rate limit return 429. The /health endpoint and the documentation pages need no key.

Rate limits

PlanRequests / minuteHistoryBulk export
Every customer2,000FullYes

Limits are counted per key per wall-clock minute. Poll the change feed once a minute rather than re-pulling /v1/programs.

Programs

GET /v1/programs searches the current dataset. All filters are optional and combine with AND.

ParameterTypeNotes
qstringSubstring match on domain, name or policy URL
platformenumhackerone, bugcrowd, intigriti, yeswehack
sourceenumsecuritytxt, diodb, or any platform id
bountyenumyes = confirmed paying, no = unconfirmed or VDP-only
expiryenumvalid, expired, missing (security.txt Expires state)
limitint1 to 1,000, default 100
offsetintDefault 0
sortenumdomain, expiry, expires_on, updated_at
 
curl -s "$BASE/v1/programs?expiry=valid&bounty=yes&limit=50" -H "X-API-Key: $VDP_KEY"

Single record: GET /v1/programs/{domain}. The response includes the program and its last 20 change records.

Change feed

The feed is append-only and ordered newest first. Use it for monitoring.

ParameterTypeNotes
sinceISO 8601Rows with ts >= since; timezone-aware
kindenumadded, removed, changed
domainstringHistory for one program
limitint1 to 1,000, default 200
 
curl -s "$BASE/v1/changes?since=2026-11-21T00:00:00Z&kind=added" -H "X-API-Key: $VDP_KEY"

Store the newest ts you have seen and pass it back next time. changed rows carry the exact field names plus before and after values.

Errors

Errors return a JSON body with a detail string.

StatusWhen
401Missing, invalid or revoked key
403Admin key required for /admin/*
404Unknown domain or change id
422Parameter failed validation, for example a bad enum
429Tier rate limit exceeded

Cadence and coverage

The scanner crawls the next Tranco slice every 15 minutes, rebuilds the merged dataset, and records the diff. Upstream platform data refreshes daily. Coverage restarts at the top of the list and wraps, so every domain is revisited.

Current coverage and the last scan run are exposed at GET /v1/stats and GET /v1/runs.

Every key sees the full history. There is no window and no backfill to buy.
